# Northbound Dispatch — Brand Assets

Standalone logo and social files. The mark is a stylized **N** with an upward
orange arrow (north = up = "northbound"), matching the favicon and the site header.

## Files

| File | Use |
|------|-----|
| `logo-wordmark-dark.svg` | Full logo for **dark / navy** backgrounds (white wordmark). Transparent canvas. |
| `logo-wordmark-light.svg` | Full logo for **light / white** backgrounds (navy wordmark). Transparent canvas. |
| `social-profile.svg` | Source for the square social/profile image (1000×1000, navy field). |
| `social-profile.png` | Rendered 1000×1000 PNG — upload directly to Instagram, Facebook, LinkedIn, Google Business, etc. |
| `../website/assets/favicon.svg` | Favicon / app-icon mark (already wired into the site). |

To re-render the PNG after editing the SVG, point any SVG rasterizer (or headless
Chrome) at `social-profile.svg` and export at 1000×1000.

## Palette

| Color | Hex | Role |
|-------|-----|------|
| Navy | `#0D1B2A` | Primary background / wordmark on light |
| Orange | `#FF6B35` | Accent (arrow, "DISPATCH", CTAs) |
| Teal | `#1B998B` | Secondary accent / tagline |
| Light | `#F7F7F7` | Light surfaces |
| Grey | `#5A6B7B` | Muted text |

## Typography

A condensed bold sans is used for the wordmark (Barlow Condensed / IBM Plex Sans
in design; the SVGs fall back to an Arial Narrow / Helvetica stack so they render
anywhere with no font install). Body copy is a clean grotesque; monospace
(Courier-style) is used for contact details on print pieces.

**Tagline:** *Your loads. Found. Confirmed. Done.*
